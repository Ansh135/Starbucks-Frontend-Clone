# Starbucks Frontend Clone

This is a frontend clone of the Starbucks website, designed to replicate the look and feel of the original website. It uses modern web development technologies and techniques for styling and responsiveness.

## Features

- **Responsive Design**: Adapts seamlessly to different screen sizes.
- **Modern UI**: Styled to match the Starbucks branding.
- **Interactive Elements**: Includes basic animations and hover effects.

## Technologies Used

- **HTML5**: For the structure of the website.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactivity and dynamic content.

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Ansh135/Starbucks-Frontend-Clone.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Starbucks-Frontend-Clone
   ```
3. Open `index.html` in your web browser to view the website.
